# ADR-011 — No Mandatory Cloud Account

- **Status:** Accepted
- **Date:** 2026-08-14
- **Source:** [plan.md §3, §37, §59](../plan.md#3-what-v01-will-not-build)

## Context

The v0.1 first-run journey must be: Install → Open → New notebook → New page → Write — within seconds, with no account, email, cloud setup, or unrelated permissions. Telemetry is not a product requirement; privacy is.

## Decision

**No mandatory cloud account, no mandatory telemetry, no cloud-first storage** in v0.1 ([plan §3](../plan.md#3-what-v01-will-not-build)).

- The app is fully usable without any telemetry.
- Optional anonymous crash reporting (if introduced later) must be opt-in or clearly disclosed, privacy-preserving, disabled for note contents, removable, and open about what is collected ([plan §37](../plan.md#37-telemetry-philosophy)).
- No permissions unrelated to the immediate user action are requested ([plan §59](../plan.md#59-recommended-v01-user-journey)).

## Consequences

### Positive

- Zero-friction onboarding; trust and privacy by default.
- No account infrastructure to build or maintain in v0.1.
- Open-source credibility: users can audit exactly what the app does with data.

### Negative

- No cloud backup/sync in v0.1; users rely on local durability and manual export.

### Neutral

- Sync is planned later as optional/self-hosted (WebDAV) through prepared seams ([plan §60](../plan.md#60-future-roadmap-compatibility)).
