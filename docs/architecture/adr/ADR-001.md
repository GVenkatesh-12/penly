# ADR-001 — Kotlin + Android Native

- **Status:** Accepted
- **Date:** 2026-08-14
- **Source:** [plan.md §4, §61](../plan.md#4-recommended-technology-stack)

## Context

Penly is a handwriting application whose primary requirement is premium interaction quality: low stylus latency, fluid pan/zoom, and reliable palm rejection on Android devices. The product must remain local-first, open-source, and future-compatible with desktop ports and collaborative features.

## Decision

Build on **Android with Kotlin** as the primary platform and language.

- Kotlin for application code, leveraging coroutines, Flow/StateFlow, and Kotlin Serialization.
- Jetpack Compose for application UI with a custom design system on top of Material 3.
- Native Android View/rendering primitives for the performance-critical ink surface.

## Consequences

### Positive

- Direct access to the most mature stylus input and palm-rejection support on the market (Android).
- Kotlin's coroutines and Flow fit the local-first, async storage model.
- Multi-module Kotlin keeps core logic portable for future Kotlin Multiplatform desktop/iOS work.
- Large talent pool and tooling ecosystem for contributors.

### Negative

- Desktop support requires a later porting effort (KMP), not automatic.
- Native rendering primitives require disciplined boundaries so Compose does not leak into core.

### Neutral

- Non-goal reminders: full desktop client, iOS client, and web are explicitly deferred ([plan §3](../plan.md#3-what-v01-will-not-build)); this decision keeps the door open rather than closing it.
